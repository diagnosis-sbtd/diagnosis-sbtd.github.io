# Diagnosis website

Jekyll source for the Diagnosis website, published with GitHub Pages at
<https://diagnosis-sbtd.github.io>.

## Local preview

```bash
bundle install
bundle exec jekyll serve
```

## Media

The method animation and the decision-tree figure are generated by the scripts in `tools/`:

| Script | Output |
|---|---|
| `tools/build-method-pipeline-media.py` | `assets/media/method-pipeline.mp4`, `assets/media/method-pipeline-poster.svg` |
| `tools/build-decision-tree-figure.py` | `assets/media/decision-tree.svg`, `assets/media/decision-tree.png` |

They need `rsvg-convert`, Graphviz (`dot`), and `ffmpeg`.
